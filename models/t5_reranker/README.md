# T5 照片候选重排

T5 从 T3 的前 50 张视觉近邻里选一张真实训练照片，输出它的经纬度。对每个原图和它的扩散变体，先取最高视觉相似度，同一原图只占一个候选名额。

```text
T5 得分 = T3 得分 + λ × T1 图片与候选坐标的余弦相似度
T3 得分 = 视觉相似度 − γ × min(|查询年份 − 参考年份| / 50, 1)
```

T3 沿用其验证集选出的 γ，缺失年份时年份扣分为零。T1 的图片端和位置端都使用查询照片的日期区间，缺失时沿用 T1 的日期缺失编码。T5 固定两个编码器，在完整验证集上选取使地理误差中位数最小的非负 λ，平局取更小的权重。λ 为零时，候选及赢家均与 T3 一致。测试集共用同一个 λ。

## 拟合与评估

在仓库根目录运行以下三个入口。尖括号表示应替换的路径。`<图库>` 包含 `features/`、`meta/` 及实际使用的训练划分，`<T3目录>` 包含本次 T3 的 `summary.json` 和 `predictions.parquet`。两份编码器权重须来自同一训练条件。输出选择新的目录。

```text
python -m models.t5_reranker.candidates --t3-dir <T3目录> --data-root <图库> --split-csv <图库划分> --checkpoint <T3使用的T0.pt> --output-dir <候选目录>
python -m models.t5_reranker.rerank --candidates <候选目录> --data-root <图库> --split-csv <图库划分> --t0 <T3使用的T0.pt> --t1 <T1.pt> --output <T5结果目录> --device cuda
python -m models.t5_reranker.evaluate --t5 <T5结果目录>/predictions.parquet --t3 <T3目录>/predictions.parquet --t1 <T1网格预测.parquet> --data-root <原始真实数据目录> --split-csv <原始真实划分> --candidates <候选目录> --output <T5结果目录>/comparison.json
```

第一步重建已记录的 CPU T3 候选，核对纯视觉与按年份重排的赢家。第二步在验证集选定权重后才计算测试集预测。输出包括模型 `T5.pt`、所有候选权重的验证结果 `validation.json`、逐图预测 `predictions.parquet` 和含输入输出指纹的 `run.json`。第三步按同一张真实查询照片配对比较 T3 和 T5，并以 T1 的独立网格预测作参照。

## 给一张新照片定位

输入项目使用的 768 维原始 CLIP ViT-L/14 图片向量，保存为形状为 `(768,)` 或 `(1,768)` 的 `.npy` 文件。有日期时提供两个端点，未知时省略。模型文件打包了 T0、T1 权重以及 γ 和 λ。推理需要拟合时使用的图库缓存和划分，单张查询无需真实坐标或任何预先计算的候选。

```text
python -m models.t5_reranker.predict_photo --model <T5结果目录>/T5.pt --data-root <图库> --split-csv <图库划分> --feature <查询特征.npy> --date-min 1910 --date-max 1920 --device cuda
```

输出含获选照片的 `neighbor_id`、`lat_pred`、`lon_pred`、视觉名次和各项得分。与 T3 一样，预测只能取自真实训练照片的坐标。

## 8,192 张扩散图的本地实验

使用 176,308 张真实训练照片及其 8,192 张变体。T3 的 γ 为 1，T5 用全部 29,529 张验证照片从 14 个预设 λ 中选中 1。下表按同一张查询照片配对统计。误差为大圆距离中位数，命中线为 25 km。

| 划分 | T3 → T5 中位误差 | T3 → T5 命中率 | 净增命中 |
| --- | ---: | ---: | ---: |
| 验证集 | 25.36 → 22.13 km | 49.69% → 53.04% | +987 |
| 常规测试 | 29.43 → 26.70 km | 45.38% → 48.22% | +1,349 |
| 伯尔尼留出 | 93.60 → 93.49 km | 5.48% → 6.96% | +50 |
| 提契诺留出 | 84.28 → 85.59 km | 3.12% → 2.97% | −20 |

对常规测试集的 93 个地理块做 1,000 次配对重采样，25 km 命中率增幅的 95% 区间为 2.01–3.64 个百分点。该区间衡量地理块的抽样差异，此次实验只使用一组已训练好的编码器。本机检查点与逐图结果保存在仓库工作区的 `data/local_runs/t5_aug8192/results/`。
